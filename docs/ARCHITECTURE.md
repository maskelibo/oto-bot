# Architecture

## Layers
1. Claude governance layer
2. CEO and agent registry
3. Memory and experiment ledger
4. Strategy and backtest engine
5. Risk gate and analytics
6. Execution adapters and paper trading

## Default operating model
- CEO starts each cycle.
- Hypothesis is generated and logged.
- A strategy is tested.
- Risk gate evaluates.
- Result is saved into episodic/failure/promotion memory.
- CEO decides whether to iterate or promote.
